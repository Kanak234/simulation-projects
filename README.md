# Simulation Projects

Ten discrete-event simulations, each self-contained in its own folder with a
`main.py` and a written report.

| # | Simulation |
|---|---|
| 01 | Hospital emergency department |
| 02 | Bank ATM queue management |
| 03 | College exam hall allocation |
| 04 | Water treatment plant |
| 05 | Library circulation |
| 06 | Irrigation scheduling |
| 07 | Call centre |
| 08 | Defect detection |
| 09 | Public transport bus scheduling |
| 10 | Retail store inventory |

## Run

Each is independent:

```bash
cd 01_Hospital_Emergency_Simulation
python3 main.py
```

Some write a `results.txt` and chart images next to the script.

## Reports

Every folder carries a `.docx` report describing the model, its assumptions
and the results.

## Status

Coursework. Each simulation runs on its own; there is no shared package and no
test suite.
